# Как залить игру на GitHub без возни с 945 файлами

Идея простая: 941 файл игры берём готовыми с GitHub одним кликом, а сверху кладём только 4 файла из этой папки.

---

## Шаг 1. Убрать сломанный репозиторий

Он всё равно неполный и будет мешать занять красивый адрес.

1. Зайди на `https://github.com/pbelyaev1/pbelyaev1.github.io`
2. **Settings** → пролистай в самый низ → **Delete this repository**
3. GitHub попросит вписать имя репозитория для подтверждения — впиши `pbelyaev1/pbelyaev1.github.io`

## Шаг 2. Форкнуть оригинал

1. Открой `https://github.com/autosam/Tamaweb`
2. Справа сверху нажми **Fork** → **Create fork**
3. Через несколько секунд у тебя в аккаунте появится полная копия игры — все 945 файлов, ничего загружать не нужно

## Шаг 3. Дать репозиторию красивое имя

1. В своём форке: **Settings** → самое верхнее поле **Repository name**
2. Впиши `pbelyaev1.github.io` → **Rename**

Этот шаг необязательный. Если пропустить, адрес будет `pbelyaev1.github.io/Tamaweb/` — тоже работает.

## Шаг 4. Положить сверху 4 файла из этой папки

В репозитории нажми **Add file** → **Upload files**.

Перетащи в окно браузера сразу всё содержимое этой папки: два файла `index.html` и `styles.css`, и две папки `src` и `resources`. Структуру папок GitHub сохранит сам и подложит файлы в нужные места, ничего лишнего не удалит.

Внизу нажми **Commit changes**.

Файлов всего 4, так что ограничение в 100 файлов даже близко не мешает.

| Файл | Что делает |
|---|---|
| `index.html` | подключены два скрипта русификации (две строки в конце) |
| `styles.css` | добавлен блок `@font-face` — кириллица пиксельным шрифтом |
| `src/i18n.js` | сам переводчик, новый файл |
| `resources/data/ru.js` | словарь перевода, новый файл |

## Шаг 5. Включить Pages

1. **Settings** → **Pages**
2. Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**
3. Подожди пару минут, обнови страницу — появится ссылка

Открой её и нажми **Cmd+Shift+R**, чтобы браузер не показал старую версию из кэша.

---

## Если что-то не так

Проверь в репозитории, что рядом с `index.html` лежат папки `src` и `resources`. Если их нет — значит форк не сработал, вернись к шагу 2.

Проверить, что перевод подключился: открой `https://твой-адрес/src/i18n.js` — должен показаться текст файла, а не ошибка 404.

---

## Как обновлять потом

Когда я пришлю новую версию словаря — просто загрузи новый `resources/data/ru.js` тем же способом (Add file → Upload files). Один файл, десять секунд.

Когда автор оригинала выпустит обновление игры — в своём форке нажми **Sync fork**. Твои 4 файла при этом останутся на месте, перевод продолжит работать.
